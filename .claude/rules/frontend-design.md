# Frontend Design Rules

- NUNCA usar Inter, Arial, Roboto como font principal
- NUNCA usar gradientes violetas sobre fondo blanco
- Siempre elegir una dirección estética clara antes de codear
- Usar CSS variables para colores y tipografías
- Preferir layouts asimétricos sobre centered genéricos
- Tailwind: evitar patrones cookie-cutter (todo rounded-xl + shadow-md)
- Animaciones con intención: un page load bien orquestado > muchos micro-effects dispersos

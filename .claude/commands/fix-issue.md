# /project:fix-issue — Resolver un issue

Recibís la descripción de un bug o problema. Seguí estos pasos:

1. **Reproducir:** Entendé el problema. Pedí más contexto si falta.
2. **Diagnosticar:** Identificá la causa raíz. Buscá en el código relevante.
3. **Proponer:** Explicá brevemente qué vas a cambiar y por qué.
4. **Implementar:** Aplicá el fix con el mínimo cambio necesario.
5. **Verificar:** Si es posible, corré los tests o indicá cómo testear manualmente.

Reglas:
- No tocar código que no está relacionado al issue.
- Si el fix implica un cambio arquitectónico, preguntar antes de proceder.
- Siempre explicar qué causó el bug para que se aprenda.
